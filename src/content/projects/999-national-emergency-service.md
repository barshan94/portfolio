An academic desktop application concept for organizing citizen requests across nine service categories, backed by a SQL Server database.

- Offers request options for Police, Fire Service, Ambulance, COVID special service, Women & Child Protection, Anti-Corruption, Child Helpline, Doctor, and Government Services.
- Uses National Identity Card (NID) details for registration and login, with profile updates that preserve the NID identifier.
- Records each service request with a date, time, and selected Bangladesh division/location.
- Includes an admin panel for reviewing registered users and service requests, plus a login table intended to show current sessions.

This is an academic project and conceptual portfolio presentation, not a live emergency dispatch service or an official government system.
