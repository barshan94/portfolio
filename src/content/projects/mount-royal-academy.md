A complete school management website for Mount Royal Academy.

**Public pages:**

- Home with school overview and announcements
- Admission page with application flow
- Academic calendar
- Notice board

**Admin dashboard (Supabase auth):**

- Manage admissions and applications
- Publish notices and calendar events
- Manage photo gallery
- Site settings

Built with Astro 7 and Supabase (PostgreSQL + Auth + Storage).
