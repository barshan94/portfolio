07 — Flagship project

Money Calculator

Evolving personal project

A personal-finance platform built around a ledger-first approach, traceable financial changes and reliable balance calculations.

Transaction→Ledger→Balance→Audit Trail

The engineering problem

  • Corrected transactions leave old balance effects behind
  • Repayments become disconnected from their original loans

Design principle

  • Balances follow underlying records, never the reverse
  • Edits, voids and reversals stay auditable
  • Every row is ownership-aware via PostgreSQL RLS

Documented capabilities

  • Multi-account tracking
  • Income, expenses, transfers, donations
  • Transaction ledger (debit/credit)
  • Auditable edits, voids, reversals
  • Lending, borrowing, repayments
  • Loan grouping
  • Tuition students, fees, partial payments
  • Deposits, investments, long-term assets
  • Budgets, savings goals, recurring activity
  • Reports, cash-flow, net-worth, forecasting
  • Auth + ownership-aware DB operations
